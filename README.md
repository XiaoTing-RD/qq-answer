# 海参的唤醒 v1.3（QQ 消息朗读 + 语音回复）

一个 Android 独立应用：读取 QQ 通知 → 用 TTS 朗读 → 你说话 → 转成文字 → 复述并问「确认发送吗」→ 你说「确认」后才通过 QQ 通知的「直接回复」接口发出。

不需要 root、不需要 Xposed/LSPosed、不修改 QQ 本体。用的是 Android 官方「通知使用权 + 通知直接回复（RemoteInput）」能力。

- 已在本机验证：`assembleDebug` 构建成功，`lintDebug` 通过（只有资源/兼容性类警告）
- 现成安装包：`C:\Users\lenovo\Desktop\海参的唤醒.apk`（约 5.8 MB，debug 签名，自己用足够）
- 未在真机上做端到端测试（本机没有连接安卓设备），首次使用请先拿小号/朋友测试
- 源码：https://github.com/XiaoTing-RD/qq-answer （tag：`v1.3`）

## 0. v1.3 语音回复排误（本次重点）

v1.2 已确认：收消息、朗读、提醒音乐、林霏专属监听都正常。v1.3 专门修语音回复：

1. **不再静默跳过**：识别失败会念出具体原因，例如「没听清」「麦克风权限被拒绝」「系统拦住了语音识别」「手机没有可用的语音识别服务」
2. **自动重试一次**：没听清/网络慢/识别器忙/系统拦截时，会提示「再说一次」并重新收音；第二次仍失败才放弃，绝不会乱发
3. **等 TTS 彻底结束**：朗读完成后先留 480ms 缓冲，再「滴」一声开麦，避免 TTS 尾音/音频焦点抢占麦克风
4. **收音窗口加长**：回复阶段 15 秒、确认阶段 12 秒；仍然不说话才会跳过
5. **应用内自检**：「声音与闹铃」卡片里新增「语音识别：可用/不可用」和「测试」按钮；失败会写入「最近错误」
6. **TTS 看门狗**：个别 TTS 引擎不回调「播放完成」时，超时后自动进入收音，不会一直卡住
7. **权限复查**：每轮收音前重新检查麦克风权限；如果系统收回了「仅本次」权限，会直接念出来

如果你测试后还是不能语音回复，先看第 7 节「还是不能语音回复」的排查顺序，并把应用里显示的「最近错误」原文发我。

## 1. 为什么不是「QQ 插件」

QQ 没有公开的插件 API。市面上的 QQ 机器人/插件基本靠改包、Xposed 或协议登录，容易封号。这个方案完全在 QQ 外面工作：

1. 系统把 QQ 的新消息通知交给本应用（通知使用权）
2. 本应用朗读通知里的「谁 + 说了什么」
3. 语音识别把你说的话转成文字
4. 复述草稿，等你语音确认
5. 用 QQ 通知自带的 `RemoteInput` 直接回复，不打开聊天界面

因此有两个硬条件：**QQ 必须弹通知**，且通知里带**可直接回复的输入框**（大部分 QQ 8.x + Android 7 以上都支持）。

## 2. 功能

- **只朗读指定好友，默认「林霏」**；其他人的消息完全不读、不回复
- 朗读好友消息，默认不读群消息（可开；群消息也只匹配这个名字）
- 消息里自动带发送者昵称
- 说完自动复述草稿，只有听到「确认/确定/发送」等明确词才发
- 说「不回/不用/取消/算了/等一下」跳过或取消
- 识别不清时最多重试一次，仍不清楚就取消，绝不乱发
- 识别失败会念出具体原因（权限/后台被拦/无语音服务/网络等），并写入应用内「最近错误」
- 应用内提供语音识别自检和 15 秒测试，方便区分「系统没服务」还是「骑行时被后台限制」
- 发送失败会保留内容并弹提醒，可在通知栏「重试」或「打开 QQ」
- 常驻前台服务，屏幕熄灭也能工作（需关电池优化）
- 粉色简约卡片界面 + 落樱飘落动画（底图取自 `流歌\pic`）
- 收到消息可播放手机本地音乐当闹铃（开关可控，自选文件，最长 6 秒）
- 声音预设：可莉感高音童声、元气少女、温柔女声、清爽少年、清晰播报
- 通知栏按钮：重听 / 取消 / 停止

## 3. 声音：关于「可莉音」

**原神可莉的原声做不了，也不建议做。** 官方没有可莉 TTS 接口，游戏语音文件有版权，提取/克隆用于自制软件属于侵权；网上所谓「可莉语音包」也大多是拆包素材。所以这里给的是「近似可爱童声」，不是可莉本音。

已内置（在应用里直接选、点「试听」）：

| 预设 | 音高 | 语速 | 感觉 |
|---|---|---|---|
| 可莉感 · 高音童声 | 1.55 | 1.05 | 最接近「小小只」的卡通感，建议配童声引擎 |
| 元气少女 | 1.32 | 1.05 | 活泼但不刺耳 |
| 温柔女声 | 1.08 | 0.96 | 夜间/安静环境 |
| 清爽少年 | 1.18 | 1.00 | 中性、清楚 |
| 清晰播报 | 1.00 | 0.96 | 风大、戴头盔时最清楚 |

更接近的方案（按投入从低到高）：

1. **换一个带童声的 TTS 引擎（推荐先试，零代码）**
   - 安装「讯飞语音+」等带童声/少女声的 Android TTS 引擎
   - 系统设置 → 语言和输入 → 文字转语音（TTS）输出 → 选这个引擎 → 下载中文语音包
   - 回本应用选「可莉感」或「元气少女」，点试听
   - 童声引擎 + 1.1~1.2 音高通常比普通女声硬拉到 1.55 更自然
2. **云端童声（最像，需要 API Key，需我再加一个模块）**
   - 微软 Azure：`zh-CN-XiaoshuangNeural`（童声，气质最接近可莉）、`zh-CN-XiaoyiNeural`（少女）
   - 火山引擎/阿里云也有童声，效果接近
   - 需要联网和密钥；可以离线合成到本地再播，减少流量
3. **本地神经网络 TTS（离线、免费，但工程量大）**
   - sherpa-onnx + 中文 VITS 童声模型，装进 App 里，首次下载模型后完全离线
4. **可莉原声/克隆：不做。** 没有官方授权渠道。

现在这个版本用的是系统 TTS（离线可用），所以换引擎就能明显改变音色，不用改代码。

## 4. 部署（最快路径：直接装 APK）

### 4.1 传到手机并安装

1. 把 `C:\Users\lenovo\Desktop\海参的唤醒.apk` 传到手机：
   - USB 数据线拷贝，或
   - 用 QQ「我的电脑/文件传输助手」发到手机 QQ，再保存到文件管理器
2. 在手机上点开 APK。系统提示「未知来源」时，允许当前文件管理器/浏览器安装。
3. 安装完成后先不要急着开开关，按下面顺序授权。

> 这个 APK 是 debug 签名，只适合自己用。以后如果用 Android Studio 重新构建，签名会变，安装前要先卸载旧版。

### 4.2 应用内四项授权（按顺序点）

打开「海参的唤醒」：

1. **通知使用权**
   - 点「通知使用权」按钮
   - 在列表里找到「海参的唤醒 · QQ 消息」，打开开关
   - 如果按钮没跳到列表：设置 → 通知与状态栏 → 通知使用权（不同品牌叫「特殊应用权限」「通知读取权限」）
2. **麦克风**
   - 点「麦克风」→ 允许
   - 必须选「仅在使用中允许」或「始终允许」，**不要选「仅本次」**；选了「仅本次」，你锁屏/离开应用后系统会收回麦克风，语音回复必然失败
3. **通知权限**
   - Android 13 以上会弹系统授权，点允许
   - 如果已经拒绝过，按钮会跳到本应用的通知设置，手动打开
4. **后台运行**
   - 点「后台运行」→ 允许忽略电池优化
   - 再到系统设置里补充（不同品牌路径见下）

状态全部变成绿色「已授权」后，点「试听」，确认能听到中文女声。

### 4.3 设置只读对象（默认「林霏」）

应用「骑行模式」卡片里有：

- 开关「只处理这个人的消息」：默认开
- 输入框：默认填了「林霏」
- 「保存」按钮

要点：

- 这里填的是 **QQ 里你给对象设置的备注名**（如果没设备注，就填通知标题显示的昵称）
- 必须和通知标题完全一致，多一个字、少一个空格都不行；改完点保存，立即生效
- 其他人的消息会被直接忽略，不会朗读、不会回复
- 如果对象改了备注，这里也要同步改
- 如果开启「朗读群消息」，群里只有这个昵称发的消息会被读（仍建议关群）

### 4.4 设置 QQ（关键）

QQ → 左上角头像 → 设置 → 消息通知：

- 新消息通知：开
- **通知显示消息详情：开**（不开只能读到「你收到一条新消息」，无法朗读内容）
- 锁屏显示消息详情：开（可选）
- 群消息：按需；本应用默认不读群，需要读群时在应用里打开「朗读群消息」
- 免打扰的群/好友不会发通知，本应用自然也读不到

系统设置 → 应用管理 → QQ → 通知：

- 允许通知：开
- 锁屏通知：显示内容
- 后台运行/省电策略：不受限制

部分 ROM 还要在 QQ 里关掉「PC 登录时手机静音通知」之类的选项，否则手机不弹通知。

### 4.5 设置提醒音乐（可选）

1. 应用「声音与闹铃」卡片里，打开「收到消息时播放本地音乐」
2. 点「选择本地音乐」，用系统文件选择器挑一首手机里的歌（mp3/m4a/flac/ogg 等）
3. 选完会自动打开开关，并显示文件名；点「试听闹铃」确认音量
4. 之后每次收到对象的消息：先播放最多 6 秒音乐，然后朗读消息、进入语音回复
5. 不想用就关掉开关；换歌重新选一次即可

说明：

- 不需要存储权限，走系统文件选择器（SAF）；权限会持久保留
- 音量走「媒体音量」，手机静音/勿扰模式可能不出声
- 如果歌曲被删除、移动，或重启后系统收回了权限，重新选一次；播放失败会自动跳过音乐直接朗读，不影响回复

### 4.6 打开骑行模式

回到应用，打开「骑行模式」右侧的开关。

- 通知栏会出现常驻通知「海参的唤醒 · 已开启，等待 QQ 消息」
- 用另一个号给这个 QQ 发一条文字消息测试

如果通知栏没有常驻通知，说明服务没起来：检查麦克风权限、电池优化、后台限制。

### 4.7 第一次测试脚本

测试号在 QQ 里的备注必须改成「林霏」（或者在应用里暂时关掉「只朗读指定好友」），否则消息会被过滤，看起来像没反应。

让朋友/小号发：`明天九点老地方？`

手机应读出：`林霏说：明天九点老地方？。要回就说。` 然后「滴」一声开始收音。

你说：`好的，我提前十分钟到`

手机应复述：`发给林霏：好的我提前十分钟到。确认发送吗？` 再「滴」。

你说：`确认`

手机说：`已发送`，QQ 里应该立刻出现这条回复（标点可能被识别服务去掉）。

再测三种情况：

- 不说话：约 9 秒后自动跳过，不会发任何东西
- 说「不回」：跳过
- 复述后说「取消」/「不对」：取消

## 5. 日常使用方式

1. 骑车前：打开应用开关，戴上耳机，手机放口袋/骑行服后袋，锁屏即可
2. 来消息：先播放提醒音乐（如果开启），再朗读「谁说了什么」，然后提示「要回就说」
3. 想回：听到「滴」后直接说内容（尽量短，5~15 个字识别最稳）
4. 听到复述后说「确认」才发送；说「取消」放弃
5. 不想回：什么都不说，或说「不回」
6. 想重听：下拉通知栏点「重听」
7. 收工：通知栏点「停止」，或在应用里关开关

音量走媒体音量，骑车前把媒体音量调到能听清但不盖住环境声。

## 6. 重要限制（先看，避免踩坑）

- **只读对象靠通知标题匹配**。应用只认「只朗读指定好友」里填的名字，默认「林霏」；QQ 备注/昵称变了就要同步改，否则会被当成其他人过滤掉。
- **必须是 QQ 弹出通知的消息**。你正开着和对方的聊天框、QQ 被系统冻结、对方被免打扰时，都可能不弹通知。
- **只能读文字通知**。QQ 语音消息通常只显示「[语音]」，无法转写；图片显示「[图片]」。本应用不做语音消息转写。
- **自动回复依赖 QQ 通知里的直接回复按钮**。少数 QQ 版本/主题不提供，此时会走「发送失败 → 保留内容 → 通知栏重试/打开 QQ」。这不是封号接口，但发送失败时仍需你停车手动处理。
- **语音识别依赖系统识别服务**（通常是 Google 语音服务或厂商语音服务）。没有中文离线包、服务被禁用、或风噪太大时会识别失败；失败只会取消，不会乱发。
- **提醒音乐依赖你选中的本地文件**。文件被移动/删除、或系统重启后收回 URI 权限时，音乐会自动跳过并直接朗读；重新选一次即可。音乐和朗读都走媒体音量。
- **确认词可能误听**。所以设计成「复述 + 二次确认」，且模糊时取消。但任何语音确认都不是 100% 安全，重要消息建议停车看一眼。
- **不要边骑边看屏幕**。本应用的目标就是让你不看屏幕，但遇到发送失败/识别异常，请靠边停车再处理。
- 蓝牙耳机：朗读会走蓝牙媒体声道；麦克风用手机还是耳机麦取决于机型和识别服务，风噪大时把手机放在胸口口袋更稳。
- Android 14+ 对后台启动麦克风前台服务有限制，本应用是从界面里手动开启的，所以合规；如果系统重启后服务没起来，重新打开应用开关即可。
- 本应用是通知监听器，能读到所有通知标题/内容（系统限制）。代码只处理 QQ 包名，不采集、不联网上传。

## 7. 常见问题

**Q：完全没反应，不朗读**
1. 应用内「通知使用权」是否已授权
2. 开关是否打开、通知栏是否有常驻通知
3. QQ 是否开启了「通知显示消息详情」
4. 给 QQ 发消息时 QQ 是否真的弹了通知（可以锁屏试）
5. 把本应用和 QQ 都加入电池白名单/自启动，锁定后台

**Q：开了「只处理这个人的消息」后完全没反应**
1. 看这个好友在 QQ 通知标题里显示的名字（备注名优先），和输入框里的名字逐字核对
2. 改完点「保存」；名字里不要多空格
3. 临时关掉这个开关测试：如果关掉能读，说明就是名字不匹配
4. 对象改了 QQ 备注后，这里也要一起改

**Q：还是不能语音回复（v1.3 先按这个查）**
1. 打开应用 →「声音与闹铃」→ 看「语音识别：可用/不可用」→ 点「测试」，说一句话，15 秒内应显示识别文字
2. 如果自检就失败，看「最近错误」原文：
   - **手机没有可用的语音识别服务**：系统没有标准 ASR。安装/启用 Google 语音服务（Speech Services by Google）或厂商语音引擎；部分国产 ROM 只允许自家 App 调用，第三方无法使用，这种情况需要改用离线识别方案
   - **麦克风权限被拒绝**：设置 → 应用 → 海参的唤醒 → 权限 → 麦克风 → 仅在使用中允许（不要选仅本次）
   - **系统拦住了语音识别**（ERROR_CLIENT）：后台录音被系统/省电策略拦截。电池设为无限制、允许自启动、锁定后台再试；部分 ROM 必须让应用保持前台才能识别
   - **网络不可用/服务连接断开**：换网络，或在系统语音服务里下载中文离线包
   - **没听清/等待超时**：靠近麦克风、一次说短句；v1.3 会自动再问一次
3. 如果自检能识别，但骑车时不回复：回到应用看「最近错误」，把原文发我；多半是锁屏后的后台麦克风限制
4. 确认麦克风不是「仅本次」：这个选项离开应用后会被系统收回，表现就是自检正常、上路就失败
5. 蓝牙耳机麦克风是否被识别服务采用，因机型和识别服务而异；风噪大时把手机放在胸口口袋，或先用手机麦测试
6. v1.3 在识别失败时会直接念出原因，并写入「最近错误」，不会再静默跳过

**Q：一直识别成奇怪的内容**
- 换安静环境测试；说话离麦近一点；一次只说一句
- 系统识别服务对带口音的短句也会出错，这是正常现象；应用会复述让你确认

**Q：不能自动发送，出现「回复没有发出」**
- 该 QQ 通知没有直接回复按钮（QQ 版本/通知样式）
- 通知已被清理/合并，原会话通知不在了
- 点通知里的「重试」；仍失败就「打开 QQ」手动发（内容已保留在通知里）
- 更新 QQ 到较新版本，关闭 QQ 的「简洁通知/通知过滤」类开关

**Q：提醒音乐不响，或只响一下就停**
- 确认「收到消息时播放本地音乐」已打开、下面显示了文件名
- 调大媒体音量；静音/勿扰模式会让它不出声
- 音乐本来只播最多 6 秒，然后开始朗读，这是设计
- 文件被移动/删除、或重启后权限失效：重新点「选择本地音乐」
- 在线音乐/DRM 缓存可能不允许被其他应用播放，换一首本地 mp3/m4a

**Q：声音太机械/不像童声**
- 换 TTS 引擎和中文语音包，见第 3 节
- 音高不要一味拉高，1.1~1.3 往往更自然
- 需要真童声就上云端 TTS（Azure 晓双）或本地神经 TTS

**Q：耗电吗**
- 常驻通知本身很轻；主要耗电来自每次朗读和收音的几十秒。骑行 2~3 小时一般没问题，但建议带充电宝。

**Q：会不会封 QQ 号**
- 本方案不登录协议、不改 QQ、不注入进程，只使用 Android 官方的通知回复接口，风险远低于第三方 QQ 插件。但「自动回复」本身仍建议只对熟人使用，不要群发/营销。

## 9. 工程结构

```
app/src/main/java/com/ridevoice/qq/
  MainActivity.kt        权限引导、开关、只读对象、声音/音乐选择、试听
  QQListener.kt          通知监听：过滤 QQ、只读对象匹配、取标题/正文、去重
  RideService.kt         前台服务 + 对话状态机（提醒音乐→朗读→收音→复述→确认→发送）
  Speaker.kt             系统 TTS 封装、音高/语速预设、音频焦点闪避
  VoiceInput.kt          SpeechRecognizer 封装、15 秒窗口、错误分类、音频焦点
  MusicAlarm.kt          本地音乐闹铃：MediaPlayer + 最长 6 秒 + 音频焦点
  ReplySender.kt         从通知 Action + RemoteInput 直接回复
  SakuraView.kt          落樱飘落动画（自绘花瓣，不占资源）
  Prefs.kt               设置、声音预设、只读对象、音乐 URI

app/src/main/res/drawable-nodpi/bg_sakura.jpg   粉色底图（由 流歌\pic 素材生成）
```

状态机：

```
IDLE → ALERT → SPEAKING → LISTEN_REPLY → LISTEN_CONFIRM → 发送
         ↓ 取消/重听      ↓ 静音/不回      ↓ 取消/听不清
       停止/重读         下一条          取消，绝不发送
```

发送安全策略：

- 只有识别结果包含确认词、且不含否定词时才发送
- 第一轮听不清会重问一次，第二轮仍不清楚直接取消
- 收音超时、识别服务报错、TTS 异常都不会触发发送

## 10. 隐私与安全

- APK 没有申请 `INTERNET` 权限，应用本身不联网、无统计、无广告
- 通知内容只在手机本地处理，不写入日志、不上传
- 但系统语音识别/TTS 由第三方服务提供，是否上传音频取决于你选择的识别/合成引擎，请自行确认其隐私设置
- 通知使用权可以读取全部应用通知，这是系统机制；代码按包名只处理 `com.tencent.mobileqq` / `com.tencent.qqlite`
- 骑行安全优先：任何需要看屏幕/手动输入的情况，先靠边停车
